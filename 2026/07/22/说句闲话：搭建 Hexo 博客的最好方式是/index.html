本篇 Blog 面向 Windows 系统，如果是 Linux 可以摸索一下试试，大体思路不变。（为什么我要提这个，因为我的三稿是在 Arch Linux 上改的。。。）

你需要：一台电脑，一个 Github 账号。没有账号的话可以去注册一个，一个邮箱就行。你说什么？没有电脑？

第 1 节：开始之前

下载 Git, Node.js，然后安装。

在 Github 中创建一个公开的 Repo，名称设为 你的名字.github.io。

打开 Repo，创建一个 index.html，随便写点东西。然后等一会，可以到 Settings/Pages 去看看，等到显示 Your site is live at https://你的名字.github.io/ 就可以访问了。

在本地创建一个 空文件夹。这里称之为 /ROOTDIR。

2.2 节：创建 SSH 连接

编辑 C:\Users\用户名\.gitconfig 。在后面加上：

现在在 Git Bash 中输入 ssh-keygen -t rsa -C "Your Github Email"。然后连按三次回车使用默认设置（没有密码）。它应该会显示出一幅字符画（这似乎还挺好看的？）。

接着，打开 C:\Users\用户名\.ssh\, 复制 id_rsa.pub 的内容。打开 Github 设置。点击 New SSH key，随便取个标题，然后粘贴刚才的内容，最后保存。

现在你的 SSH 应该连上了。如果要测试，可以在 Git Bash 中测试：ssh -T git@github.com。它应该会返回 Hi username! You've successfully authenticated...。测试时，关掉 Watt Toolkit 或者别的加速器，不然可能会失败！

于是你成功配置好了与 Github 的 SSH 连接！现在，就差最后一个小节就可以上传你的博客了！

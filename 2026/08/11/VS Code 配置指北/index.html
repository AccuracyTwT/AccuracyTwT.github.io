VS Code 配置指北

大抵是很简单的，需者自取。

这是一篇 VS Code 的配置指北，还有一个便携版。（不会真的有人在 Linux 下不会配置吧……）

在此之前，先在本地建一个文件夹。注意，路径中不能有中文！

请选择你的编译器

如果有且已加入环境变量可跳过。

Mingw-w64 GCC

前往 Mingw-w64，下载 Mingw-w64-Builds。在 Github 界面下选择 x86_64-xx.x.x-release-posix-seh-ucrt-rt_v14-rev1.7z，下载。如果下的慢可以 使用 PCL2 下载 使用各种光速下载器。

然后解压，找到 /mingw64/bin/，复制路径。右键此电脑，点击属性，进入高级系统设置，点击环境变量。更改 Path 环境变量（为自己安装就改上面的，否则改下面的），新建项，把路径复制进去，记得带末尾的 \，确定退出。

新开一个 cmd 窗口，输入 g++ -v 和 gdb -v，如果输出了一大堆东西就成功了。

配置插件

启动 Code.exe，关掉它的 Getting Started。现在打开 Extensions（可以按 Ctrl + Shift + X，也可以点击左边工具栏最后一个图标打开），搜索 C/C++ Extension Pack，安装。等待安装完毕。

如果想要使用中文，下载 Chinese (Simplified) (简体中文) Language Pack for Visual Studio Code，安装后重启 VS Code 即可。建议在最后再装中文，否则有概率出现问题。

其实那么多编译选项有一些不是必需的，一般可以采用以下几种：

配置调试运行

调试是十分重要的！

打开左边第四个图标，Run and Debug。点击一行小字 create a launch.json file，创建 launch.json。一般会先让你选择 GDB/LLDB 还是 Windows，选择 GDB/LLDB。其实这个并不重要。进入界面后会显示一些下拉框，如果被点掉了就点击 Edit Configurations。选择 (gdb) Launch。找到 "program" 一行，把后面的内容替换为 "${fileDirname}\\${fileBasenameNoExtension}.exe"，也就是 tasks.json 中 "args" 的第五行。将 "externalConsole": false 改为 "externalConsole": true（创建小黑框）。把 "miDebuggerPath" 改为 "gdb"。最后，在最后加上 "preLaunchTask": "C/C++: g++.exe build active file"。

自定义

非必选，可以自行 BDFS。

隐藏 exe 文件

点击左下角的设置图标，选择 Settings，切到 Workspace 菜单栏。搜索 Files: Exclude，增加一项 **/*.exe。保存之后你发现 exe 文件就被隐藏了。

更改字体

Consolas 其实不太好看，推荐使用 Jetbrains Mono。前往 官网，下载字体并安装。然后回到 Workspace 设置，修改 Font Family，在最前面加上 'Jetbrains Mono'，用逗号隔开。重新打开 VS Code 后你就能够使用 Jetbrains Mono 了。

接下来启用连字符特性。可以参照 Jetbrains Mono 官方仓库 README.md 原文：

Visual Studio Code

  1. From the File menu (Code on Mac) go to Preferences → Settings, or use keyboard shortcut Ctrl+, (Cmd+, on Mac).
  2. In the Editor: Font Family input box type JetBrains Mono, replacing any content.
  3. To enable ligatures, go to Editor: Font Ligatures, click Edit in settings.json, and copy this line "editor.fontLigatures": true into json file.

其实只需要在 settings.json 中增加一句 "editor.fontLigatures": true 即可。

题目描述

给定一个 1∼n1 ∼ n1∼n 的排列 pip_ipi​，接下来有 mmm 次操作，操作共两种：

  1. 交换操作：给定 xxx，将当前排列中的第 xxx 个数与第 x+1x+1x+1 个数交换位置。
  2. 询问操作：给定 kkk，请你求出当前排列经过 kkk 轮冒泡排序后的逆序对个数。

进行一轮冒泡排序指：

Solution

设 cic_ici​ 为第 iii 个数前面比它大的数的个数。注意到进行一轮冒泡排序会使得 ci=max⁡{ci−1,0}c_i = \max\{c_i-1, 0\}ci​=max{ci​−1,0}，答案为所有 cic_ici​ 的和。使用树状数组维护即可。

洛谷 P6155

题目描述

给定一个长度为 nnn 的整数序列 aia_iai​，再给定一个长度为 nnn 的整数序列 bib_ibi​。

你可以进行一些修改，每次你可以将一个 aia_iai​ 增加 111，花费为 bib_ibi​，你需要使所有的 aia_iai​ 不相等，且同时满足花费最少。

你可以在修改前进行无限次如下操作：交换 bi,bj (1≤i,j≤n)b_i,b_j \ (1 \leq i,j \leq n)bi​,bj​ (1≤i,j≤n)。

求最小的花费。

Solution

显然先排序。

如果让 aia_iai​ 移到 aja_jaj​，再让 aja_jaj​ 移到 aka_kak​ 的话一定更劣，所以只需要把多余的移到空位上。于是维护一个集合，把每个位置扫一遍，遇到空位就拿一个数出去，遇到多余的数就放进来。

不难发现这样移动长度的总数不变。然后我们可以尽可能让长的更长，短的更短。这样可以把集合换成栈，每次弹出栈顶的数。最后将所有数移动的长度排序，对应 bib_ibi​ 便能轻松通过。

洛谷 P2519

题目描述

一次考试共有 nnn 个人参加，可能出现多个人成绩相同的情况。第 iii 个人说：“有 aia_iai​ 个人成绩比我高，bib_ibi​ 个人成绩比我低。”

Solution

首先对于 ai+bi≥na_i + b_i \ge nai​+bi​≥n 的可以先排掉了。

现在一个 iii 就是指成绩排序后 ai+1∼n−bi+1a_i+1 ∼ n-b_i+1ai​+1∼n−bi​+1 都是相同的。把相同的区间合并。由于所有的区间都在 1∼n1 ∼ n1∼n 间，而又有 nnn 个成绩，所以只需要选出正确的区间，中间的空隙可以由说谎的人来填上。

题目描述

可以转化为求每个 aia_iai​ 到 a1∼ai−1a_1 ∼ a_{i-1}a1​∼ai−1​ 的最小汉明距离。

Solution

洛谷 P11335

题目描述

Emily 是一只外星章鱼，她正在玩一个街机游戏。

游戏机上有 NNN 个按钮，从左到右编号为 111 到 NNN。游戏的规则是按照时间顺序按下 MMM 个按钮，每秒按一个按钮。在第 TiT_iTi​ 秒时，需要按下按钮 AiA_iAi​。注意，可能存在 Ti=TjT_i = T_jTi​=Tj​ 且 Ai=AjA_i = A_jAi​=Aj​，即使 i≠ji \neq ji=j。

发现按钮 iii 能够到达按钮 jjj 必须满足 ∣ai−aj∣≤tj−ti|a_i - a_j| \le t_j - t_i∣ai​−aj​∣≤tj​−ti​，即

{aj−ai≤tj−tiai−aj≤tj−ti \begin{cases} a_j - a_i \le t_j - t_i \\ a_i - a_j \le t_j - t_i \end{cases} {aj​−ai​≤tj​−ti​ai​−aj​≤tj​−ti​​ ∴{tj−aj≥ti−aitj+aj≥ti+ai \therefore \begin{cases} t_j - a_j \ge t_i - a_i \\ t_j + a_j \ge t_i + a_i \end{cases} ∴{tj​−aj​≥ti​−ai​tj​+aj​≥ti​+ai​​

故把每一个按钮看作 (ti+ai,ti−ai)(t_i + a_i, t_i - a_i)(ti​+ai​,ti​−ai​)，对第一维排序，就变成了 LIS 最小链覆盖，可以由 Dilworth 定理转化为最长反链长度，求最长下降子序列即可。

洛谷 P11340

题目描述

给出三种赛场中 nnn 个人的能力排名。每次可以选择两名未被淘汰的选手和一个赛场，在该赛场中能力较弱的选手会被淘汰。经过 n−1n-1n−1 轮比赛后，剩下的最后一人即为胜者。现有两种操作：

操作一：给出一个数 XXX，询问 XXX 是否有可能成为胜者；
操作二：给出三个数 P,A,BP, A, BP,A,B，交换第 PPP 种赛场中排名为 AAA 和 BBB 的选手。

Solution

暴力地，有一个做法：建图，对于一个选手 iii，连一条边到 TA 能够在一个场馆上战胜的选手。每一次从 xxx 开始 BFS，如果能够遍历到所有的点就有可能赢得比赛。

注意到如果 iii 能打败 jjj，而 jjj 能够 AK，则 iii 也能 AK（让 jjj 把别人全打败，最后让 iii 打败 jjj）。于是我们可以优化我们的暴力。

对于建出来的图缩点强连通分量。容易看出第一个强连通分量中的人都是胜者。考虑这个强连通分量的性质。容易证明，对于这个强连通分量里的 aaa 和该强连通分量外的 bbb，必有 aaa 能够在任意场所战胜 bbb。所以，这里面的人必定是每一个场地排名中的前缀。

故能找到一个 iii，满足排名在 iii 之前的都是胜者，之后的都不可能获胜。容易发现，iii 为第一个满足三个场地上长度为 iii 的前缀包含的选手集合相同的数。使用数据结构维护即可。

洛谷 P14057

题目描述

知更鸟有 nnn 个杯子，编号为 111 到 nnn，每个的容量都为 mmm。现在，第 iii 个杯子里水的体积为 aia_iai​。

她可以进行若干次操作，每次可以选择两个不同的杯子 iii 和 jjj ，并把 iii 中的所有水倒入 jjj 中。如果操作后 jjj 中的水的体积大于 mmm，那么 jjj 中的水的体积会溢出到只剩 mmm。

完成这些操作后，她需要保证杯中水的体积单调不减，且留下水的总体积尽量大。你需要帮她求出总体积的最大值。

特殊性质：有至少一个杯子为空。

Solution

考虑特殊性质的做法。发现可以用空杯子交换，能够耗费 000 的水。于是用最小和次小做一个空杯子出来即可，记得特判序列有序。

洛谷 P9377

题目描述

有 2n2^n2n 个点，iii 和 jjj 间有一条长度为 apopcount(i⊕j)⁡a_{\operatorname{popcount(i \oplus j)}}apopcount(i⊕j)​ 的边。同时还有 mmm 条边，第 iii 条边连接 uiu_iui​ 和 viv_ivi​，长度为 wiw_iwi​。求 sss 的单源最短路。

Solution

直接做是不现实的。对于这种建完全图的题目，有经典的 Trick：建虚点和拆点。考虑维护 xxx 取反 jjj 位后的值。然而这个还是不好维护，但是 nnn 只有 171717，可以按位决策。

具体地，点 (x,y,z)(x, y, z)(x,y,z) 表示目前这个值是 xxx，它是由一个数在前 yyy 位，取反了 zzz 位的值。我们建这几种边：

{(x,y,z)→(x,y+1,z)(x,y,z)→(x⊕2y,y+1,z+1)(x,y,z)→(x,0,0)(ui,0,0)↔(vi,0,0) \begin{cases} (x, y, z) \to (x, y+1, z) \\ (x, y, z) \to (x \oplus 2^y, y+1, z+1) \\ (x, y, z) \to (x, 0, 0) \\ (u_i, 0, 0) \leftrightarrow (v_i, 0, 0) \end{cases} ⎩⎨⎧​(x,y,z)→(x,y+1,z)(x,y,z)→(x⊕2y,y+1,z+1)(x,y,z)→(x,0,0)(ui​,0,0)↔(vi​,0,0)​

前两种边边权都是 000，第三种边权为 aza_zaz​，最后一种边权为 wiw_iwi​。这样就相当于一位一位考虑，但是不在考虑时计算距离，而是延后到决定时再计入。但还是无法通过。

发现这里有很多 000 的边。类似于 01BFS，直接使用 BFS 一次松弛完这些点，只有在有边权的点才对优先队列进行操作。然后不用记录辅助点的 dis，卡卡就过了。

第 iii 件物品在甲看来价值为 aia_iai​，在乙看来价值为 bib_ibi​。两人的估值互不影响。

∀x∈B, ∑i∈Aai≥∑i∈Bai−ax \forall x \isin B, \ \sum_{i \isin A} a_i \ge \sum_{i \isin B} a_i - a_x ∀x∈B, i∈A∑​ai​≥i∈B∑​ai​−ax​ ∀x∈A, ∑i∈Bbi≥∑i∈Abi−bx \forall x \isin A, \ \sum_{i \isin B} b_i \ge \sum_{i \isin A} b_i - b_x ∀x∈A, i∈B∑​bi​≥i∈A∑​bi​−bx​

洛谷 P11158

题目描述

给定一个矩阵，矩阵中每一个数都是 000 或 111，每一行和每一列都有且仅有一个 111。

定义 f(i,j)f(i, j)f(i,j) 为交换第 iii 行和第 jjj 行后，矩阵中元素都是 000 的大小为 n2×n2\frac{n}{2} \times \frac{n}{2}2n​×2n​ 的子矩阵的个数。

考虑固定子矩阵的列为 x,x+1,…,x+n2−1x, x+1, \dots, x+\frac{n}{2} - 1x,x+1,…,x+2n​−1。现在可以把问题抽象为：

我们发现因为子矩阵的大小为 n2\frac{n}{2}2n​，所以 aaa 中 000 和 111 的个数相等，都为 n2\frac{n}{2}2n​。于是只有交换后 000 全部连续才能做出贡献，而且一种交换方式最多贡献 111。

可以进行分讨，如果原来就是连续的就可以块内交换、块外交换，以及 1110000011→11000001111110000011 \to 11000001111110000011→1100000111。否则容易发现可以贡献序列中长度为 n2\frac{n}{2}2n​ 而其中共有 n2−1\frac{n}{2}-12n​−1 个 000 的连续子序列个数的贡献，然后这个东西不超过 444 个，而且必定由这四个位置开始：x,x−1,y,y−1x, x-1, y, y-1x,x−1,y,y−1。这里记 xxx 为第一个 000 的位置，yyy 为第二个 000 的位置。记得判重。

然后这可以用一个线段树做掉，注意到普通线段树可以 O(log⁡n)O(\log n)O(logn) 求全局第 kkk 个 000。所以可以 O(log⁡n)O(\log n)O(logn) 的求出固定一列的答案。我们发现移动原来固定的列最多只会对 aaa 中的两个元素做出改变，直接维护即可。

时间复杂度 O(nlog⁡n)O(n\log n)O(nlogn)。
